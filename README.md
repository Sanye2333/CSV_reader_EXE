# CSV_reader_EXE
# CSV 简易数据分析工具
 基于 PyQt6 + Pandas + Matplotlib 开发的通用CSV可视化桌面分析工具，开箱即用，无需编写代码。
 ## 功能特性
 - CSV文件读取：自动加载数据，识别列名与数据类型
 - 单列深度统计：自动计算数据类型、缺失值、唯一值、最值、均值、中位数
 - 分组聚合分析：按所选列分组，完成数值字段聚合运算
 - 多图表一体化展示：柱状图、折线图、直方图、相关性热力图
 - 多重数据校验：空表、空列、NaN值、未选列等异常检测，防止程序崩溃
 - 简洁Qt界面：多标签页布局，支持返回主界面、数据总览
 - 支持打包为独立EXE，无需Python环境
